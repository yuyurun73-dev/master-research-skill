# ニッチな出どころの地図（声・事実・競合の失敗）

native-ads 工程1の出どころ（Reddit・知恵袋・Ameba・note・X・5ch）は**全員が掘る場所**。差がつくのは、その外側の「小さくて濃い場所」。
ここに書いた到達状況は **2026-11-18 に curl で実測**（200=取れる／403=相手が自動アクセスを拒んでいる＝自動では取らない）。変わるので、使う前に1回確かめる。

## 0. ニッチを見つける5つの引き方（どの媒体でも効く）

1. **内輪の言葉で引き直す**：最初の収集で `analysis/kw.md` に出た専門語・略語・薬の名前・検査値・手術名（例「臼蓋形成不全」「THA」「骨切り」「PAO」）で全媒体を引き直す。一般語で引くと一般人、内輪の言葉で引くと**何年も悩んでいる濃い人**に当たる
2. **感情語×悩み語で引く**：「もう疲れた」「誰にも言えない」「情けない」「夫に」「孫に」「仕事辞め」＋悩み語。表の悩みでなく**深夜2時の悩み**が出る
3. **試した物×不満語で引く**：「<競合品・治療名> 効かない／やめた／返品／後悔／お金の無駄」。試した物リストと「なぜ効かなかったか（本人の説）」が同時に取れる
4. **サブアバターの居場所で引く**：介護・更年期・妊活・産後・受験・夜勤・立ち仕事など、**別の悩みの掲示板の中で**この悩みを話している人。サブアバターの種はここから出る
5. **時間で切る**：直近1年（今の言葉・今の競合）と5年以上前（昔からの悩み＝普遍の言葉）を分けて読む。古い1件だけの話は信じない（講義04「2011年のどこかの誰か」）

## 0.5 日本の40代以上はどこにいて、何を信じているか（総務省 令和6年度 情報通信メディアの利用時間と情報行動に関する調査・2024年12月・N=1,800）

出典：https://www.soumu.go.jp/main_content/001017160.pdf（表5-1-1・図5-1-2・表6-1-2-2・表7-2-1）。2026-11-18 PDFから直接読んだ数字。

**どこにいるか（利用率）**

| | 40代 | 50代 | 60代 | 70代 |
|---|---|---|---|---|
| LINE | 94.8% | 94.5% | 91.1% | 71.8% |
| YouTube | 91.8% | 83.0% | 71.2% | 43.3% |
| Instagram | 67.0% | 52.7% | 34.7%（前年22.6%から急増） | 10.4% |
| X | 48.7% | 43.6% | 22.1% | 8.1% |
| TikTok | 39.9% | 25.5% | 18.8% | 8.7% |
| Facebook | 38.6% | 32.1% | 26.6% | 8.1% |

**書き込む人の割合**（全年代・利用率のうち「書き込む・投稿する」）：LINE 51.0%／Instagram 18.3%／X 10.7%／Facebook 6.6%／YouTube 3.6%／TikTok 2.3%
→ 読むだけの人が大半。**書かれた声が溜まるのは、LINE（オープンチャット）・知恵袋・ブログ・YouTube/Instagramのコメント欄**。Facebook は利用は多いが書き込みは少なく、しかも外から読めない

**何を信じているか**
- メディアの信頼度（全部＋大部分信頼できる）：40代 新聞54.9%・テレビ54.6%・ネット31.7%／50代 新聞66.4%・テレビ63.0%・ネット33.0%／60代 新聞69.4%・テレビ66.4%・ネット22.5%
- 「信頼できる情報を得る」ために一番使うメディア：40代 テレビ41.8%＝ネット41.8%／50代 テレビ57.6%・ネット27.3%・新聞13.0%／60代 テレビ61.6%・新聞18.5%・ネット15.9%
→ **40代はテレビとネットが半々、50代から先はテレビと新聞が上**。工程3bで「ファネルの形とLPの見た目」を決める材料にする

**40代以上の声が取れる場所（外から読めるか・2026-11-18実測）**

| 場所 | 外から | 取り方 |
|---|---|---|
| LINEオープンチャット | 部屋の名前・説明・人数・最終発言は読める（会話の中身は参加しないと見えない） | `scripts/scrape_line_openchat.py`→`analysis/openchat_rooms.md`。人数が多く動いている部屋は、本人がアプリで参加して読む候補（書き込まない） |
| Yahoo!知恵袋・Amebaブログ・note・はてな・5ch・ガルちゃん | 読める | 既存スクリプト |
| YouTubeのコメント | 読める（40代91.8%・50代83.0%が利用） | `scrape_youtube_comments.py`。NHK・健康番組・医師の解説動画の下は50代以上が多い |
| Instagramのコメント | 投稿URLが分かれば数字は取れる（メモ instagram-likes-public-page） | コメント本文の自動取得はしない |
| Facebook（グループ・ページ・広告のコメント） | **外から読めない**（2026-11-18：公開ページもリンクプレビュー用の名乗りでも中身0・グループ検索404） | 本人がログインして参加→読んだスレを本人がコピペで渡す。本人の明示の許可がある時だけ Claude in Chrome で**読むだけ**（書き込み・反応・参加申請はしない） |
| らくらくコミュニティ・趣味人倶楽部（シニアSNS） | トップは開くが検索は404 | WebSearch「site:raku-raku.jp <語>」「site:smcb.jp <語>」で個別ページを拾う |
| 発言小町 | 読める | WebFetch。40〜50代女性の家族・夫婦の悩み |

## 5. やらないこと

- 掲示板に自分で質問を立てる（講義02の「bait thread」）は**外に向けた発信**なので、本人の許可がある時だけ
- ログインが要る場所の自動操作・cookie移植はしない（本人が1回手でログイン→以降自動、の設計にする）
- 403で拒んでいるサイトを、自動化ブラウザ・UA偽装で抜けにいかない（表の「403」は WebFetch で読める範囲か本人の手で）
- 本番SNS垢にログイン中のブラウザで自動操作しない
- 1つの出どころの1件だけの話を「傾向」にしない（3つ以上の独立した出どころで出たら「高」）
